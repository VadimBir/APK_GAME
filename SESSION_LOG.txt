GOAL (decoded from the brief)
- A fully OFFLINE, on-device Android text-adventure game where a LOCAL LLM
  narrates 80s-style interactive fiction and a LOCAL diffusion model paints a
  matching image for each story beat.
- Built by FORKING + EXTENDING an existing open-source app (Pocket Pal AI) and
  grafting on local Stable Diffusion image generation.
- Catch ALL diffusion errors (cfg/steps/resolution/sampler/OOM/missing/corrupt).
- 3 original stories inspired by 80s classics (Play-store safe, no owned IP).
- Sequential single-model loading (only one heavy model in RAM at a time).
- HuggingFace model download by default + optional edge/NPU (Qualcomm QNN) path.
- Freemium: free lite/trial, $1.99 unlock. TWO APKs: debug = free unlock for
  testing; release = real Google Play Billing.
- Sonnet agents research/"download"; Opus implements; a separate Opus auto-checker
  sanity-checks; brain model documents and pushes every checkpoint.

KEY DECISIONS (locked with the user)
- Base architecture: FORK Pocket Pal (React Native) + native Android diffusion
  module. ("Extend an APK" = fork the open-source source and rebuild.)
- Stories: 3 ORIGINAL works inspired by 80s classics (zero IP risk).
- Two-APK split implemented at BUILD-TYPE level: debug -> BILLING_BYPASS=true
  (free unlock), release -> false (real billing). Compile-time constant, so the
  bypass literal cannot reach the release bytecode.
- User mid-session: "ALL JUST DEBUG" -> focus the deliverable on the free debug APK.

RESEARCH (3 background Sonnet agents)
- Pocket Pal AI: github.com/a-ghorbani/pocketpal-ai, MIT (fork & ship OK), RN 0.82.1
  bare + New Architecture + Hermes, uses llama.rn (llama.cpp GGUF). Its ModelStore
  ALREADY does stop-await-release sequential load/unload. Build needs Node >=22.21,
  Yarn 1.22, JDK 17, NDK 27.3.13750724, compileSdk 36.
- Diffusion engine: stable-diffusion.cpp (leejet, MIT) — the ggml/GGUF twin of
  llama.cpp; ~1.5GB RAM for SD-1.5 Q4_0; deterministic new_sd_ctx/free_sd_ctx for
  load/unload. Default model: second-state/stable-diffusion-v1-5-GGUF (Q4_0).
  Fallback: MNN. Edge/NPU: Qualcomm QNN (optional, CPU fallback).
- Billing: react-native-iap v15.3.2 (Play Billing 8, MIT), product full_game_unlock
  $1.99 non-consumable, entitlement cached for offline, restore = re-query.

WHAT WAS BUILT
- Tested pure-TS core (runs under `node --test`, 33/33 green):
  * diffusion error taxonomy + native-error mapper (every failure typed) [R8]
  * diffusion param validation/clamp (cfg/steps/res/sampler/seed bounds)  [R8]
  * LLM->game JSON parser w/ repair + never-crash fallback
  * ModelGovernor single-resident state machine (load/unload/reload)       [R5]
  * EntitlementService trial gate + compile-time backend                   [R9/R10]
- Graft kit (extends the Pocket Pal fork):
  * StoryEngine (per-turn: gate -> LLM narrate -> parse -> swap -> image)
  * DiffusionEngine JS bridge (pre-flight validate, BUSY guard, QNN->CPU fallback)
  * StableDiffusionModule.kt + sd_bridge.cpp (JNI over stable-diffusion.cpp,
    serialized worker thread, native error -> typed code)
  * BillingConfigModule.kt (exposes compile-time BILLING_BYPASS to JS)
  * GameLauncher (story picker + 1-tap HuggingFace SD model download) + GameView
  * 3 story bibles: The Sunless Vault / Derelict: Signal Nine / Blackthorn Manor
- Reproducible scripts: setup-android-sdk.sh, fork-pocketpal.sh, apply-graft.sh,
  fetch-sdcpp.sh, build-apks.sh (+ _add-deps.mjs, _wire-nav.mjs).

HOW TO TEST ON A PHONE
  adb install -r dist/arcane-terminal-debug-freeunlock.apk
  Open app -> left drawer -> "Arcane Terminal":
   1) Models tab: download + load a small chat GGUF (the narrator).
   2) Tap Download for the ~1.6GB Stable Diffusion 1.5 image model.
   3) Pick a story. LLM narrates each turn; local SD paints the scene.
  Only one model is in RAM at a time (governor swaps them).
